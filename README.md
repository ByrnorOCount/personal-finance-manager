# Personal Finance Manager

Based on https://play.google.com/store/apps/details?id=com.colpit.diamondcoming.isavemoneygo

Our main adopted features: (Scope may increase once we finish these)
1. Splash Screen: App logo animation effect, automatically switches to Home screen after 2 seconds
2. Home: Display total balance, income and expenditure summary cards, quick add button (FAB), preview of the 5 most recent transactions, display current month
3. Add Transaction: Enter amount, select category (Dining, Transport, Bills, Shopping, Health, Entertainment, Others), toggle income/expense, select date, optional note, save button
4. Transaction History: Full list using RecyclerView, keyword search bar, filter by time/category/type, swipe to delete, tap to edit, color-coded income and expenses
5. Statistics: Pie chart by expense category, bar chart by month, income vs. expense comparison, highlight top spending category, compare this month with last month
6. Budget Planner: Set monthly spending limits by category, progress bar showing used/remaining, red alert when over budget, monthly budget overview, copy budget to next month
7. Settings: Name and profile picture, currency selection (VND/USD), PIN lock toggle, dark/light mode, data export (CSV/Excel), data import from file, clear all data, app version information
8. Savings Goal: Create savings goals with target amount, deadline, progress bar, mark as completed
